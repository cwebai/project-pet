# Питомец проекта

Тамагочи для клиентов SEO-агентства. Клиент выбирает питомца в начале проекта, а тот растёт, пока команда работает над сайтом. Каждая выполненная задача превращается в корм, встречи и согласования приходят уведомлениями от питомца, за достижения проекта появляются трофеи.

## Посмотреть

- **Лендинг:** https://cwebai.github.io/project-pet/
- **Демо-приложение:** https://cwebai.github.io/project-pet/demo.html — телефон клиента, личный кабинет на ПК и пульт агентства, с которого можно отправлять события.
- **Сценки встреч:** https://cwebai.github.io/project-pet/scenes.html — все питомцы за 30 минут до встречи и во время неё.

## Как пользоваться демо

1. Выберите питомца и дайте ему имя.
2. На пульте справа закройте задачу — в телефон придёт уведомление, питомца можно покормить.
3. Попробуйте встречу по шагам («Назначить встречу» → «За 30 минут до встречи»), согласование с материалами, отчёт и веху.
4. «Начать заново» в шапке сбрасывает прогресс.

Данные в демо условные, прогресс хранится только в вашем браузере.
